# StudyFlow

A study management web app to track subjects, progress, timetable and exams in one dashboard.

## Features
- Dashboard with live stats and circular progress rings per subject
- Subjects manager (add, delete, update progress, coefficients)
- Weekly timetable (courses, teachers, rooms, groups)
- Exams and quizzes tracker with upcoming deadlines
- Dark and light mode, saved between visits
- Responsive layout with a bottom navigation bar on mobile

## Tech stack
React, TypeScript, Vite, React Router, CSS variables

## Run locally
    git clone https://github.com/Mohamed-EL-Hadi/studyflow.git
    cd studyflow
    npm install
    npm run dev
